# Nyaimu Slimeball Texture（ニャイム スライムボール）

[![CurseForge](https://img.shields.io/curseforge/dt/1735468?logo=curseforge&label=CurseForge)](https://www.curseforge.com/minecraft/texture-packs/nyaimu-slimeball-texture)

日本語 | [English](README.en.md)

バニラの「スライムボール」アイテムのテクスチャを、ペットスライム「ニャイム」に差し替えるリソースパックです。変わるのはスライムボールだけで、ほかはバニラのままです。

![地面に落ちたニャイムのスライムボール](images/screenshot.png)
![インベントリ内のニャイムのスライムボール](images/screenshot_inventory.png)

## ⬇ ダウンロード

- **[CurseForge](https://www.curseforge.com/minecraft/texture-packs/nyaimu-slimeball-texture)**

対応: **Minecraft Java Edition 1.12.2 〜 26.3**（動作確認: 1.12.2 / 1.13 / 26.3）。1.13 以降では「古いバージョン向け」と表示されますが、そのまま有効にして使えます。

## 導入方法

1. CurseForge から zip をダウンロードします（解凍しないでください）。
2. `.minecraft/resourcepacks` に入れます。
3. ゲーム内の「オプション > リソースパック」で有効にします。

補足: 独自のスライムボールテクスチャを使っている Mod のアイテムは変わりません。

## テクスチャ

| バージョン | パス |
|---|---|
| 1.12.2 以前 | `assets/minecraft/textures/items/slimeball.png` |
| 1.13 以降 | `assets/minecraft/textures/item/slime_ball.png` |

どちらも 64x64 の同じ画像です。
