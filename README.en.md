# Nyaimu Slimeball Texture

[![CurseForge](https://img.shields.io/curseforge/dt/1735468?logo=curseforge&label=CurseForge)](https://www.curseforge.com/minecraft/texture-packs/nyaimu-slimeball-texture)

[日本語](README.md) | English

Replaces the vanilla **Slimeball** item texture with Nyaimu, the pet slime. Only the slimeball changes; everything else stays vanilla.

![Nyaimu slimeballs dropped on the ground](images/screenshot.png)
![Nyaimu slimeball in the inventory](images/screenshot_inventory.png)

## ⬇ Download

- **[CurseForge](https://www.curseforge.com/minecraft/texture-packs/nyaimu-slimeball-texture)**

Supports **Minecraft Java Edition 1.12.2 – 26.3** (tested: 1.12.2 / 1.13 / 26.3). On 1.13 and later, the pack is marked as made for an older version, but you can still enable and use it.

## Install

1. Download the zip from CurseForge (do not unzip it).
2. Put it in `.minecraft/resourcepacks`.
3. In game, enable it under Options > Resource Packs.

Note: mods that use their own slimeball texture are not affected.

## Textures

| Version | Path |
|---|---|
| 1.12.2 and earlier | `assets/minecraft/textures/items/slimeball.png` |
| 1.13 and later | `assets/minecraft/textures/item/slime_ball.png` |

Both are the same 64x64 image.
